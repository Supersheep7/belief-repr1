# Finding Epistemic Success in LLMs

Welcome! This project explores **epistemic success** measures in LLMs through a mix of interpretability studies and it is meant to go hand in hand with my MSc Thesis Project so titled, presented at DIKU, Copenhagen University under the supervision of Anders Søgaard. No local installation is required—just follow the Colab links below to get started. 

## Note on Usage

> **This repository is intended for browsing and reference**  
> The primary way to run and interact with the project is through the provided Colab notebooks (see [Colab Notebooks](#colab-notebooks)).  
>
> The scripts and code in this repository may differ in format or structure from the Colab versions to better support modularity and code reuse. If you wish to experiment or execute code, please use the Colab notebooks directly. Everything is designed to run in Colab, so you can experiment/replicate immediately with no setup.

## Quick Start

1. **Open a Notebook in Colab**  
   Click one of the links below to launch one of the notebooks. The first cell will copy the original drive folder in your account, so you can follow my own steps.

## Codebase Structure

- **notebooks/**  
  Contains all Colab-ready Jupyter notebooks.

- **src/**  
  Supporting code: helper modules, utilities, or core logic used by the notebooks.

- **data/**  
  Stored datasets, results, weights, etc.

- **README.md**  
  This file.

Most users only need the notebooks. The code in `src/` is modularized to keep the notebooks clean and is commented for those interested in the details.
